# Flashjot v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a cross-platform quick-capture + notebook app that stores notes as plain Markdown.

**Architecture:** Tauri 2 Rust core owns the filesystem (`store.rs`, no Tauri deps, unit-tested), settings, windows, global shortcuts and tray. A SvelteKit SPA renders two routes (`/quick`, `/notebook`) in two pre-created windows and talks to Rust through typed `invoke` wrappers.

**Tech Stack:** Tauri 2, Rust (edition 2024), SvelteKit + Svelte 5 + TypeScript, CodeMirror 6, Lucide icons, GitHub Actions `tauri-action`.

**Spec:** `docs/superpowers/specs/2026-10-19-flashjot-design.md`

## Global Constraints

- Platforms: Linux (X11 shortcuts; Wayland via `--quick`/`--notebook`), Windows 10+, macOS.
- Default shortcuts: `CommandOrControl+Alt+N` (quick), `CommandOrControl+Alt+D` (notebook).
- Notes root default `<Documents>/Flashjot`; quick notes → `Inbox/YYYY-MM-DD-HHMMSS.md`.
- All writes atomic (tmp + rename). All UI paths validated under root.
- Quick box: Enter saves, Shift+Enter newline, Esc/blur hides and keeps draft; never clears on failed save.
- UI languages: English, Türkçe (auto from OS locale).
- License MIT. Rust ≥ 1.90.

### Task 1: Store core (`store.rs`) — TDD

**Files:** Create `src-tauri/src/store.rs`; test module inside it. Add deps `chrono`, dev-dep `tempfile`.

**Produces:**
```rust
pub struct Store { root: PathBuf }
#[derive(Serialize)] pub struct NoteMeta { pub path: String /* rel, '/'-separated */, pub title: String, pub folder: String, pub modified: i64 /* ms */, pub preview: String }
#[derive(Serialize)] pub struct Folder { pub name: String, pub pages: Vec<NoteMeta> }
#[derive(Serialize)] pub struct Tree { pub folders: Vec<Folder>, pub root_pages: Vec<NoteMeta> }
#[derive(Serialize)] pub struct Hit { pub path: String, pub title: String, pub snippet: String }
impl Store {
  pub fn new(root: PathBuf) -> Self; pub fn ensure(&self) -> io::Result<()>;
  pub fn add_inbox(&self, text: &str, now: NaiveDateTime) -> Result<NoteMeta, StoreError>;
  pub fn list_inbox(&self) -> Result<Vec<NoteMeta>, StoreError>;   // newest first
  pub fn tree(&self) -> Result<Tree, StoreError>;                  // excludes Inbox, .trash, dotfiles
  pub fn read(&self, rel: &str) -> Result<String, StoreError>;
  pub fn write(&self, rel: &str, content: &str) -> Result<(), StoreError>;
  pub fn create_folder(&self, name: &str) -> Result<(), StoreError>;
  pub fn create_page(&self, folder: &str, title: &str) -> Result<NoteMeta, StoreError>;
  pub fn rename(&self, rel: &str, new_title: &str) -> Result<NoteMeta, StoreError>;
  pub fn move_to(&self, rel: &str, folder: &str) -> Result<NoteMeta, StoreError>;
  pub fn trash(&self, rel: &str) -> Result<String /* trash rel */, StoreError>;
  pub fn restore(&self, trash_rel: &str, original_rel: &str) -> Result<(), StoreError>;
  pub fn search(&self, q: &str) -> Result<Vec<Hit>, StoreError>;   // case-insensitive, max 50
}
```

Tests (write first, see them fail, then implement):
- [ ] `add_inbox` creates `Inbox/2026-10-19-143205.md` with exact text; second call same second → `-2` suffix; empty/whitespace text → `StoreError::Empty`.
- [ ] `write` is atomic: no `.tmp` left behind; content round-trips through `read`.
- [ ] Path safety: `read("../x")`, `read("/etc/passwd")`, `write("a/../../x")` → `StoreError::InvalidPath`.
- [ ] `create_page("Ideas","Robot arm")` → `Ideas/Robot arm.md`; duplicate → `Robot arm 2.md`; title with `/` or `\` rejected.
- [ ] `tree()` lists folders alphabetically, pages by title, skips `Inbox`, `.trash`, non-md.
- [ ] `rename` and `move_to` move files; target exists → numbered suffix.
- [ ] `trash` then `restore` returns file to original place.
- [ ] `search("STEP")` finds "step motor" with snippet; respects 50 limit.
- [ ] `cargo test` green → commit `feat(store): markdown note store`.

### Task 4: Windows, shortcuts, tray, single instance, autostart

**Files:** Create `windows.rs`, `shortcuts.rs`, `tray.rs`; modify `lib.rs`, `Cargo.toml` (`tray-icon` feature, plugins), `tauri.conf.json` (no default windows).
- `windows::setup(app)` pre-creates hidden `quick` (frameless, always-on-top, skip-taskbar, 560×160, transparent) and `notebook` (1000×680, min 640×420) windows. `show_quick(app)` positions on the cursor's monitor, upper third, shows + focuses, emits `quick-shown`. Notebook close request → hide.
- `shortcuts::apply(app, &Settings) -> Vec<String /*errors*/>` unregisters all and registers both.
- Single-instance callback: argv contains `--quick` → `show_quick`, else `show_notebook`. First launch with `--quick`/`--notebook` does the same; `--hidden` (autostart) shows nothing.
- Tray: Quick note · Notebook · Settings · Quit.
- [ ] Manual check: `npm run tauri dev`, press both shortcuts, tray menu works, second `flashjot --quick` forwards → commit.
