## What Flashjot does

Ideas show up at bad times: in the middle of a build, a meeting or a sentence. Opening a full
note app breaks your flow, and by the time it has loaded the idea is gone. Flashjot keeps a capture
box one shortcut away, and a notebook for when you have time to sort things out.

<CardGrid>
  <Card title="A box one shortcut away" icon="pencil">
    `Ctrl+Alt+N` opens a small box on the monitor your mouse is on, with the cursor already in it.
    `Enter` saves. See [Quick capture](/guide/quick-capture/).
  </Card>
  <Card title="Drafts never get lost" icon="approve-check">
    Press `Esc` or click somewhere else, and whatever you typed is still there next time. Saved
    notes are written so that a power cut can't leave a half-written file.
  </Card>
  <Card title="An Inbox to sort later" icon="list-format">
    Quick notes land in the Inbox as cards. Press `M` to file one into a folder and it gets a title
    from its first line.
  </Card>
  <Card title="A notebook with folders" icon="open-book">
    Pages in folders, a Markdown editor with live styling and clickable checkboxes, and search
    across everything with `Ctrl+K`. See [Notebook](/guide/notebook/).
  </Card>
  <Card title="Plain Markdown files" icon="document">
    Every note is a `.md` file in `Documents/Flashjot`. Open them in Obsidian, VS Code or any
    editor, and keep them in git or a synced folder. See [Your notes](/guide/your-notes/).
  </Card>
  <Card title="Keyboard first" icon="laptop">
    Every action has a shortcut, and you can record your own global shortcuts in Settings. See
    [Shortcuts](/guide/shortcuts/).
  </Card>
  <Card title="Linux, Windows and macOS" icon="rocket">
    Built with Tauri: it uses the system's web view instead of shipping a browser, so the installer
    is about 3 MB. Starts in the tray, ready when you are.
  </Card>
  <Card title="English and Turkish, light and dark" icon="translate">
    The interface follows your system language and light or dark setting. You can change both in
    Settings.
  </Card>
</CardGrid>

## Get it

Download the installer for your system from the
[latest release](https://github.com/mftnakrsu/flashjot/releases/latest). It is free and has no
account, no telemetry and no network access: your notes never leave your computer.
