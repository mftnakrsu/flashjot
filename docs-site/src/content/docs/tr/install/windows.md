## Kurulum

1. [Son sürümden](https://github.com/mftnakrsu/flashjot/releases/latest)
   `Flashjot_x.y.z_x64-setup.exe` dosyasını indir. Kurumun yazılımları MSI paketleriyle dağıtıyorsa
   onun yerine `Flashjot_x.y.z_x64_en-US.msi` dosyasını kullan.
2. Çalıştır. Flashjot henüz bir kod imzalama sertifikasıyla imzalı olmadığı için Windows SmartScreen
   bilgisayarını koruduğunu söyleyebilir. **Ek bilgi**'yi, sonra **Yine de çalıştır**'ı seç.
3. Kurulumu tamamla. Kurulum, Windows 10 ve 11 ile gelen Microsoft Edge WebView2'ye ihtiyaç duyar;
   olmayan nadir sistemlerde onu kendisi indirir.

Başlat menüsünden **Flashjot**'u aç. Defter açılır ve bildirim alanında bir simge belirir. Bundan
sonra Flashjot oturum açtığında orada başlar. [Hızlı kutuyu](/tr/guide/quick-capture/) denemek için
<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd>'ye bas.

:::tip[AltGr tuşlu klavye düzenleri]
Türkçe Q dahil birçok düzende Windows, <kbd>Ctrl</kbd>+<kbd>Alt</kbd>'ı <kbd>AltGr</kbd> sayar.
<kbd>AltGr</kbd>+<kbd>N</kbd> ya da <kbd>AltGr</kbd>+<kbd>D</kbd> ihtiyaç duyduğun bir karakteri
yazıyorsa [Ayarlar](/tr/guide/settings/#kısayollar)'dan başka bir kısayol kaydet; örneğin
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd>.
:::

## Kaldırma

Ayarlar → Uygulamalar → Yüklü uygulamalar → Flashjot → Kaldır. `Belgeler\Flashjot` içindeki notların
yerinde kalır.
