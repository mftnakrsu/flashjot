---
title: Shortcuts
description: Every keyboard shortcut in Flashjot, in the quick box, the notebook and the Inbox.
---

On macOS, use <kbd>⌘</kbd> wherever this page says <kbd>Ctrl</kbd>, and <kbd>⌥</kbd> for
<kbd>Alt</kbd>.

## Anywhere

These two work in every app while Flashjot runs. You can change them in
[Settings](/guide/settings/#shortcuts).

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> | Open the quick box; press again to hide it |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>D</kbd> | Open the notebook |

## Quick box

| Keys | Action |
|---|---|
| <kbd>Enter</kbd> | Save to the Inbox and close |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | New line |
| <kbd>Esc</kbd> | Close and keep the draft |

## Notebook

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Search |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New page next to the open one |
| <kbd>Ctrl</kbd>+<kbd>M</kbd> | Move the open page to another folder |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Show or hide the sidebar |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save now (pages also save by themselves) |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through the sidebar |
| <kbd>Del</kbd> | Delete the selected page in the sidebar |

## Inbox

| Keys | Action |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | Previous or next note |
| <kbd>Enter</kbd> | Open the note |
| <kbd>M</kbd> | Move it to a folder |
| <kbd>Del</kbd> | Delete it |

## Page title

| Keys | Action |
|---|---|
| <kbd>Enter</kbd> or <kbd>↓</kbd> | Rename and go to the text |
| <kbd>Esc</kbd> | Undo the change to the title |
